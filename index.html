        <h2>模块一：核心愿景 (Vision)</h2>

        <p><span class="highlight">从“被动接受者”到“共同进化”的政策设计师</span></p>

        <p>当智能体更深度地融入生活，技术治理必须超越单纯的代码逻辑。我的研究愿景聚焦于<b>技术政策建模 (Tech-Policy Modeling)</b> 与<b>人机共生中的风险治理 (Risk Governance)</b>。我致力于将计量经济学与因果推断应用于人机交互的实证场景中，寻找效率平衡与风险共担的框架。我期望将“情感伦理”与“信任”等定性概念，转化为可测量的政策参数与算法约束。</p>

    </div>


    <div class="section">

        <h2>模块二：实证项目展演 (Empirical Portfolio)</h2>


        <h3>1. 复杂系统的“风险共担”——制度韧性与外部性治理</h3>

        <span class="card-label">机器决策的风险外溢、责任归属与制度规范</span>

        <ul>

            <li><b>量化实践：</b>构建多期双重差分 (DID) 与三重差分 (DDD) 模型，实证评估 2018 年地方政府债务信息披露政策的监管效果。</li>

            <li><b>人机共生启示：</b>将金融风险传染逻辑映射到人机协同中，探索制度框架如何有效约束技术外部性与算法风险，为治理智能系统的系统性风险提供数据思路。</li>

        </ul>


        <h3>2. 人类“模糊意图”的机器解析——从情感表达到量化决策</h3>

        <span class="card-label">智能体如何解析人类意图、算法伦理</span>

        <ul>

            <li><b>量化实践：</b>对 500 篇政治演说应用自然语言处理 (NLP) 与情感分析，论证政策转变；应用机器学习与合成控制法分析 30 个经济体。</li>

            <li><b>人机共生启示：</b>证明了我具备捕捉人类复杂情感和非结构化意图，并将其转化为结构化机器决策输入的能力，这是开发同理心智能体的核心基石。</li>

        </ul>


        <h3>3. 具身智能的“社会学边界”——真实场景的痛点洞察</h3>

        <span class="card-label">具身智能走进家庭/机构、触碰隐私与情感边界</span>

        <ul>

            <li><b>量化实践：</b>深入广州城市社区，执行并回收了 500 多份关于住房、就业和社会服务的高质量微观问卷。</li>

            <li><b>人机共生启示：</b>探讨养老机器人等设备介入日常生活时隐私与情感伦理的重构，赋予宏大“人机协同”概念以真实的微观弱势群体视角。</li>

        </ul>


        <h3>4. 生产力重构与“价值分配”——人机协同的宏观经济学</h3>

        <span class="card-label">人与智能体之间的分工、协作与价值分配</span>

        <ul>

            <li><b>量化实践：</b>在北京大学市场经济研究中心使用 Python 和 Stata 分析数据点，协助起草超 50 万元国社科基金重大项目申请。</li>

            <li><b>人机共生启示：</b>当智能体作为新型“劳动力”深度参与社会分工时，必将引发劳动经济学的变革。我将在此基础上探索人机共生时代的经济公平与价值再分配机制。</li>

        </ul>
